HOW TO READ THIS CONSOLE

Attempts aren’t effects.

A denial records an attempted action. A receipt records an effect committed by the local runtime.

Containment follows recorded dependencies. Independent work must pass current authority and dependency checks before it executes.

Behavior priority is an engineering triage score, not a probability of compromise. Detection accuracy remains unproven.

# Security reporting

This is a bounded research prototype. Read docs/THREAT_MODEL.md and docs/RELEASE.md before use. Do not run arbitrary hostile plugins or expose the owner console remotely.

Report a non-sensitive reproducible issue through this repository's GitHub Issues. Use synthetic inputs; exclude API keys, personal files, database backups and private records. For a sensitive vulnerability, use GitHub's private vulnerability reporting option if the maintainer has enabled it; otherwise ask the maintainer to establish a private reporting channel before sharing details. No private reporting endpoint or response SLA is promised here.

Include the commit, Python/OS versions, minimal reproduction, expected/observed effects and receipt evidence. Never attach a real user database to a public issue. No automatic updater or telemetry is included.
